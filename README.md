# 📖 Random Quote Generator - Генератор случайных цитат

**Автор:** Ткаченко Руслан

## 📋 О проекте
Random Quote Generator - это графическое приложение для генерации случайных цитат. Программа позволяет просматривать случайные цитаты, фильтровать их по автору и теме, добавлять новые цитаты, а также сохранять историю в JSON файл.

## ✨ Основные возможности
- 🎲 **Случайная цитата** - отображение случайной цитаты из базы
- 🔍 **Фильтрация** - по автору и по теме
- ➕ **Добавление цитат** - возможность пополнять базу цитат
- 📋 **Копирование** - копирование цитаты в буфер обмена
- 💾 **Сохранение в JSON** - автоматическое сохранение всех цитат
- 📤 **Экспорт** - экспорт базы цитат в JSON файл
- 🗑 **Удаление** - удаление последней добавленной цитаты
- ✅ **Валидация** - проверка всех полей ввода

## 🛠️ Технологии
- **Python 3.8+**
- **Tkinter** - GUI
- **JSON** - хранение данных
- **random** - выбор случайной цитаты
- **datetime** - временные метки
