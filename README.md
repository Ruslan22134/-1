# 🎬 Movie Library - Библиотека фильмов

**Автор:** Ткаченко Руслан

## 📋 О проекте
Movie Library - это графическое приложение для хранения и управления информацией о фильмах. Программа позволяет добавлять, редактировать, удалять фильмы, фильтровать по жанру, году и рейтингу, а также сохранять данные в JSON.

## ✨ Основные возможности

### Управление фильмами
- ➕ **Добавление фильмов** - название, режиссер, год, жанр, рейтинг, описание
- ✏️ **Редактирование** - изменение информации о фильме
- 🗑 **Удаление** - удаление фильмов из библиотеки
- 📖 **Просмотр описания** - подробная информация о фильме

### Фильтрация
- 🔍 **По жанру** - выбор конкретного жанра
- 📅 **По году** - фильмы определенного года
- ⭐ **По рейтингу** - фильмы с рейтингом выше выбранного

### Дополнительные функции
- 🎲 **Случайный фильм** - выбор случайного фильма из библиотеки
- 💾 **Автосохранение** - все изменения сохраняются в JSON
- 📤 **Экспорт** - экспорт библиотеки в JSON файл

## 🛠️ Технологии
- **Python 3.8+**
- **Tkinter** - графический интерфейс
- **JSON** - хранение данных
- **random** - выбор случайного фильма
- **datetime** - временные метки
