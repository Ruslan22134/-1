# 🔐 Random Password Generator

**Автор:** Ткаченко Руслан

## 📋 О проекте
Random Password Generator - это графическое приложение для генерации безопасных случайных паролей. Программа позволяет настраивать длину и состав пароля, автоматически сохраняет историю сгенерированных паролей и предоставляет удобный интерфейс для копирования результатов.

## ✨ Основные возможности
- 🎚️ **Регулировка длины пароля** - от 4 до 32 символов с помощью ползунка
- ✅ **Выбор типов символов**:
  - Заглавные буквы (A-Z)
  - Строчные буквы (a-z)
  - Цифры (0-9)
  - Специальные символы (!@#$%^&*)
- 🎲 **Генерация случайных паролей** с использованием библиотеки random
- 📊 **Оценка сложности пароля** (слабый/средний/сильный)
- 📋 **Копирование в буфер обмена** одним кликом
- 📜 **История паролей** с сохранением в JSON файл
- 💾 **Автоматическая загрузка истории** при запуске
- 🗑️ **Очистка истории** по требованию
- 📱 **Удобный интерфейс** на русском языке

## 🛠️ Технологии
- **Python 3.8+** - язык программирования
- **Tkinter** - графический интерфейс
- **JSON** - хранение истории
- **random** - генерация случайных значений
- **datetime** - временные метки
